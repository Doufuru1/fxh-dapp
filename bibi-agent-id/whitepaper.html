This page contains the BIBI-specific launch logic: a 0.002 BNB base mint, 85% liquidity allocation, and 15% multi-signature treasury allocation.

DOCUMENT STATUSProduct preview · contract parameters to be verified on-chain

01 / 项目定位

Agent ID 是访问层，BIBI 是资产层。

BIBI 是一个基于 Binance Agent ID 的社区铸造项目。持有并验证 Agent ID 的地址进入铸造流程，BIBI 头像与品牌负责建立社区识别度，资金去向与市场规则由最终智能合约公开约束。

02 / 核心参数

  • 基础铸造价格0.002 BNB / share
  • 流动性注入85%
  • 多签钱包15%
  • 目标网络BNB Smart Chain
  • 访问方式Verified Agent ID

03 / 资金流向

每笔铸造支付通过合约进行拆分。85% 进入流动性池，用于后续市场深度；15% 发送至项目多签钱包，由多签成员共同管理。前端页面不持有私人密钥，也不替代区块浏览器中的链上验证。

PAYMENTMint payment用户按当前铸造档位支付 BNB。
LIQUIDITY85% → LP大部分资金为流动性池预留。
MULTISIG15% → Treasury剩余部分进入多签钱包。

04 / BIBI 分级

这里的分级不照搬参考项目的 1U 曲线。BIBI 从 0.002 BNB 基础档开始，后续档位的数量、触发条件和价格由最终合约参数决定，发布前应在公告和区块浏览器中同步确认。
