01

核心机制 Core Engines

Depth Index Engine（深度定标引擎）
把 LP 深度变成系统的"承载指数"：深度越稳，运行越从容；深度波动，节奏自动收敛，让增长始终服从真实承载力。
Compounding Flywheel（复利飞轮）
把增长做成闭环：收益优先回流，持续强化深度与韧性，让系统不是靠情绪拉动，而是靠结构自我增强。
Redemption Firewall（赎回防火墙）
压力上升自动限流，降低单位时间净流出冲击；极端场景进入防御态，优先守住稳定与连续运行。
Value Sink & Burn（价值回收与销毁）
盈利环节完成价值回收与固定比例销毁：使用越真实、回收越持续，长期强化供需结构与稀缺性。
